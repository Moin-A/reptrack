## Wiki

Project notes and documentation are in the `wiki/` folder, powered by [mdBook](https://github.com/rust-lang/mdBook).

**Install mdBook** (once):
```bash
brew install mdbook
```

**Start the wiki:**
```bash
mdbook serve --open
```

Opens at `http://localhost:3000`. Live reloads when you edit any `.md` file in `wiki/`.
